点云缓存工作台 · Windows 桌面版

解压整个目录，双击 launch.cmd。桌面窗口需要 Python 3.10+（含 Tkinter）。
HBJSON 通过桌面工具所用的 Python 处理，需要 NumPy。
BGEO.SC 序列或 ZIP 由本机已授权的 Houdini hython 处理，需要该环境的 NumPy。
工具会尝试检测默认目录下的 hython，也可在窗口手动选择。

1. 添加 HBJSON、BGEO 序列 ZIP，或添加存放一个 BGEO 序列的目录。
2. 选择输出目录，点击「只分析」看时间和粒子数据，或选处理方式生成测试缓存。
3. 点击队列中的结果查看对照。把鼠标移到图表，可以查看各帧的时间和保留记录数。
4. 打开结果目录，可找到 cache.hbjson、sequence 文件夹或 validation.json。

同一队列使用一套设置。每次运行生成一个新的批次目录。
当输入是 HBJSON 时，输出为 HBJSON。BGEO 支持原格式、HBJSON 或两者。
BGEO 的时间优先读取缓存属性。只有原数据缺少时间时才填 FPS，后备规则从源帧 1 对应 0 秒开始计算。
一个 ZIP 或目录里有多组序列时，可用 BGEO 文件匹配筛出目标序列。

隔帧抽取
  保留完整帧，保留起止时间，并为本来会消失的短命 ID 补留整帧。
  可勾选保留每个 ID 首末记录所在整帧。结果会报告首末采样偏移。

隔帧＋关键采样
  适用于 HBJSON。先隔帧保留整帧，其余时间点按 ID 补回首末记录及超出误差上限的原记录。
  可保留位置转折。位置和速度阈值使用源缓存单位，默认 0.03 和 0.5。

逐 ID 自适应
  按每个 ID 的轨迹独立筛选中间采样。两种稀疏采样方式都要求播放端按原始时间和 ID 插值。

图表展示存储的采样记录，不代表运行时活粒子数。验证报告用于核对数据，实际观感请在 Houdini 或 UE 播放比较。
输出始终另存。
